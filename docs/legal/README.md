**Chop etishdan oldin** sariq `[...]` joylarni to'ldiring: operator nomi, aloqa,
sana, server joylashuvi, o'chirish muddati.

**Joylashtirish (bepul):** o'z serverimizda nginx orqali — `tools/ops/` dagi
konfiguratsiya `/legal/` yo'lida shu papkani beradi
(`https://<server>/legal/maxfiylik-siyosati.html`). GitHub Pages private repo
uchun bepul emas.

Ilovadagi qisqa matnlar (`kTermsSummary`, `kPrivacySummary` —
`customer_settings_page.dart`) shu sahifalarga mos bo'lishi shart.
